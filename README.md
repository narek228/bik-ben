# Telegram-бот: ChatGPT + Claude с оплатой кредитами

Бот-обёртка над OpenAI и Anthropic API. Пользователь выбирает модель,
платит за пополнение баланса кредитами (крипта или ЮKassa), каждое
сообщение списывает кредиты по фактической стоимости токенов + наценка.

## Структура проекта

```
config.py       — все настройки и цены моделей
database.py     — SQLite: пользователи, баланс, транзакции, платежи
llm_client.py   — унифицированный вызов OpenAI/Anthropic + расчёт стоимости
payments.py     — создание платежей ЮKassa и NOWPayments (крипта)
bot.py          — Telegram-хендлеры + запуск (точка входа)
```

## Установка

```bash
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

Заполните `.env`:

1. **BOT_TOKEN** — получить у [@BotFather](https://t.me/BotFather)
2. **OPENAI_API_KEY** — https://platform.openai.com/api-keys
3. **ANTHROPIC_API_KEY** — https://console.anthropic.com/settings/keys
4. **YOOKASSA_SHOP_ID / YOOKASSA_SECRET_KEY** — регистрация магазина на
   https://yookassa.ru (нужно юрлицо или самозанятость/ИП)
5. **NOWPAYMENTS_API_KEY / NOWPAYMENTS_IPN_SECRET** — регистрация на
   https://nowpayments.io, привязать крипто-кошелёк для вывода

## Запуск

```bash
python bot.py
```

Бот поднимет:
- Telegram-поллинг (получение сообщений)
- aiohttp-сервер на порту 8080 (приём webhook от NOWPayments)
- фоновую задачу опроса статусов платежей ЮKassa

## Что нужно донастроить перед реальным запуском

- **Домен и HTTPS** — NOWPayments должен достучаться до `PUBLIC_WEBHOOK_URL`
  публично. Проще всего: VPS + nginx + Let's Encrypt, либо туннель типа
  ngrok/Cloudflare Tunnel для теста.
- **Курс USD_TO_CREDIT_RATE** — сейчас захардкожен, в проде подтягивайте
  актуальный курс ЦБ РФ через API (например, cbr-xml-daily.ru) вместо
  ручного обновления .env.
- **MODEL_PRICING** — сверьте с актуальными ценами на сайтах OpenAI и
  Anthropic перед запуском, цены на токены периодически меняются.
- **Лимиты и антифрод** — стоит добавить rate-limit на количество
  сообщений в минуту от одного пользователя (например, через
  `aiogram.utils.chat_action` + простой счётчик в Redis), иначе злоумышленник
  может засыпать бота запросами и сжечь ваш баланс у провайдера быстрее,
  чем вы получите оплату (актуально при использовании тестовых кредитов).
- **Юридическая часть** — почитайте Terms of Service OpenAI и Anthropic:
  реселлинг доступа к их API через собственный интерфейс с оплатой обычно
  разрешён, но требования могут меняться, проверьте актуальную версию.
- **PostgreSQL** — при заметной нагрузке замените SQLite на Postgres
  (структура таблиц в `database.py` останется почти такой же).

## Как это работает "под капотом"

1. `/start` — создаёт юзера в БД с бесплатными кредитами на пробу
   (`SIGNUP_BONUS_CREDITS` в config.py)
2. `/model` — выбор модели (2 от OpenAI, 2 от Anthropic)
3. `/topup` — выбор суммы и способа оплаты → создаётся платёж во внешней
   системе → юзеру даётся ссылка на оплату
4. После оплаты (webhook от NOWPayments или опрос статуса ЮKassa) —
   кредиты зачисляются на баланс автоматически
5. Любое текстовое сообщение → бот сначала **резервирует** (списывает)
   оценочную максимальную стоимость запроса → отправляет запрос в
   OpenAI/Anthropic → после ответа **корректирует** списание по факту
   (возвращает переплату) → если API упал с ошибкой — деньги возвращаются
   полностью
